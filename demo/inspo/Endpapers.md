## Shortlist for the Bindery run

![[attachments/endpaper-01.svg]]
Indigo and gilt — the harbour-chart palette, reused
> Works because the gilt is a hairline, not a field. Any wider and it
> competes with the marbling instead of edging it.
> Reach for it when a dark cover needs a warm interior. See [[Quire Structures]].
#marbled #indigo

![[attachments/endpaper-02.svg]]
Walnut ink over cream. Warmest of the set
> The rule here is one pigment, two dilutions — the variation is water,
> not a second colour.
#marbled #warm

![[attachments/endpaper-03.svg]]
Sage and bone. Too quiet for a cover, right for endpapers
> Quiet is the point: an endpaper is read for two seconds while the book
> opens. Use where the cover is already loud.
#printed #green
